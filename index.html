멀티내비 개인정보 처리방침

시행일: 2026년 11월 6일

멀티내비(이하 "앱")는 개발자 개인(이상희)이 만든 앱으로, 개발자가 운영하는 서버가 없습니다. 앱은 사용자의 개인정보를 개발자에게 보내지 않으며, 개발자는 사용자의 개인정보를 수집·보관하지 않습니다. 아래는 앱이 휴대폰 안에서 다루는 정보와, 앱에 포함된 Google 기능이 다루는 정보입니다.

1. 휴대폰 안에만 저장되는 정보

  • 목적지 검색어, 목적지 이름·주소·좌표, 최근 목적지, 즐겨찾기, 마지막으로 연 내비, 앱 설정
  • 목적: 최근 목적지·즐겨찾기를 다시 쓰고, 고른 내비로 바로 안내하기 위함
  • 이 정보는 휴대폰 안에만 저장되고 개발자나 다른 곳으로 보내지 않습니다.
  • 보유 기간: 사용자가 앱에서 지우거나 앱을 삭제할 때까지 (앱을 삭제하면 함께 지워집니다)

2. 내비 앱 화면 읽기 (자동 비교, 화면 공유)

  • 사용자가 [자동 비교]를 누르면, 사용자가 Android 화면 공유에 동의한 경우에만 앱이 띄운 티맵·카카오내비·네이버지도의 검색 목록과 경로 화면을 읽어 예상 시간·거리를 비교합니다.
  • 화면 글자 인식은 휴대폰 안에서만(Google ML Kit, 기기 내 처리) 하며, 화면 이미지는 저장하거나 전송하지 않습니다.
  • 비교가 끝나거나 사용자가 [취소]를 누르면 화면 공유를 바로 멈춥니다.

3. 사용 정보 접근 (선택)

  • 떠 있는 전환 버튼을 3개 내비 앱 위에서만 보여 주고, 내비가 길 안내 중인지 확인하기 위해 지금 앞에 열려 있는 앱이 무엇인지만 확인합니다.
  • 다른 앱의 사용 기록을 저장하거나 전송하지 않습니다.
  • 허용하지 않아도 앱의 다른 기능은 사용할 수 있습니다. Android 설정 > 사용 정보 접근에서 언제든 끌 수 있습니다.

4. 알림 접근 (선택)

  • 내비 전환 시 이전 내비의 길 안내가 끝났는지 알기 위해, 3개 내비 앱의 길 안내 알림이 있는지만 확인합니다.
  • 알림 내용을 읽거나 저장·전송하지 않으며, 다른 앱의 알림은 다루지 않습니다.
  • 허용하지 않아도 앱의 다른 기능은 사용할 수 있습니다. Android 설정 > 알림 접근에서 언제든 끌 수 있습니다.

5. 다른 앱 위에 표시

  • 내비 앱 위에 비교 안내 카드와 떠 있는 전환 버튼을 보여 주기 위해 사용합니다. 정보를 수집하지 않습니다.

7. 아동

  • 앱은 만 14세 미만 아동을 대상으로 하지 않습니다.

8. 사용자의 권리
